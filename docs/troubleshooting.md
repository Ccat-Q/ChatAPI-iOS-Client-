# 故障排查

## 无法解锁

先确认设备已配置密码或生物识别。取消认证后可点击明确的解锁按钮再次尝试；返回前台不会自动循环弹出验证。默认进入后台后需要重新解锁。可在“更多 → 应用安全”关闭“Face ID / 设备密码锁”，关闭后不再要求启动或返回前台解锁；敏感管理操作仍需设备验证，服务器登录仍然有效且受验证。重新开启立即生效。若实际设备发生生物识别交互问题，请记录设备、系统版本、前后台顺序；自动回归没有模拟系统认证界面。

## 无法登录或恢复

- 地址应为 `https://chat.example.com/` 这样的服务器根地址。子路径部署目前不支持；无效实例可直接在登录页删除，不必先登录。
- 默认 HTTPS。HTTP 只适用于明确启用该选项的开发实例；它不跳过 TLS 证书错误。
- 启用 TOTP 时填写验证码；启用验证码、OIDC 或禁用本地密码时使用“网页登录 / SSO”。在服务器页面完成登录后点击“完成登录”。部分提供方可能禁止内嵌浏览器，需按该提供方的受支持登录方式另行设计适配。
- 恢复时停在验证错误页：先检查网络与服务器，再点击重试。临时错误不会删除标记。
- 服务器明确未认证或返回 401 后会回到登录页；403 通常是权限或 CSRF/Origin 配置问题，不代表 Cookie 必然过期。
- Keychain 会话标记不包含 Cookie。服务器 Cookie 不可恢复时需要重新登录。
- 多台服务器共用主机名但端口不同，系统 Cookie 可能互相影响。为独立实例分配不同主机名。
- API 若重定向到另一个域名、端口或 HTTP，会被客户端拒绝。实例地址应填写最终服务器地址，代理应直接处理 API 路由。

## 工作台为空或重连

连接成功以收到有效快照为准。检查反向代理是否转发 `/api/ws` 的 WebSocket 升级和 Cookie，并查看当前账号是否有会话。无会话时显示空列表；有更多会话时列表底部提供分页按钮。

切换标签、打开详情保持同一工作台连接；进入后台、退出登录或切换实例会断开。前台已验证会话不重复验证，WebSocket 直接执行 Cookie 握手。会话验证请求和首次快照均有 15 秒等待上限；断线按 1 秒起步、最长 30 秒退避，可点击“立即重连”跳过等待。重连后恢复时间线订阅，403 权限失败不会无限自动重试。

仍然缓慢时，分别记录“正在验证会话”和“正在连接工作台”哪个阶段耗时，并检查服务器 `/api/auth/session`、代理 `/api/ws` 升级和网络延迟。客户端消除重复请求不能解决服务器响应、DNS 或代理本身的延迟。协议解码失败会显示错误，不再静默伪装为空列表。

发送超时或断线时，服务器可能已执行但确认未到达；输入保留。先检查时间线再重试，避免重复回复。旧请求已关闭或被新请求替换时，从列表重新进入当前会话。

## 设置保存失败

只读字段与对象/数组字段不提供编辑。数字只在提交时解析；空值、非有限值、小数整数或超出范围会在请求前拒绝。敏感字段更改需要明确确认与设备认证。

补丁只发送变化字段。服务端仍可因为权限、依赖约束或版本差异拒绝；按错误修正。成功响应可能包含重启要求和“保存成功但运行状态协调失败”的警告，不能忽略。

## 看不到 Bark / 测试失败

Bark 入口取决于 `/api/mobile/v1/capabilities` 是否成功声明 `bark`。普通上游服务器不一定包含该扩展；不应修改客户端绕过能力声明。

输入设备 Key 后先保存，成功后输入框清空。空 Key 表示保留服务端已有 Key。测试使用服务端已经保存的目标，因此未配置目标时不可测试。通知投递、密钥加密和事件触发属于服务端范围。

## Actions 失败

先查看 `regressions`、`archive`、`screenshots` 三个并行任务，再查看 `build` 汇总；归档成功不代表回归或截图成功。

- SDK 检查失败：确认 `macos-26` runner 镜像提供 Xcode/iOS 26+，不要降低部署目标来掩盖 SDK 缺失。
- 回归失败：查看首个具体断言或 Swift 编译错误；测试服务只绑定随机本地端口，不需要生产凭据。
- 归档失败：查看首个 Swift / actool 错误；勿仅凭末尾的 `ARCHIVE FAILED` 判断根因。
- dSYM 不存在：确认 Release 归档使用 `DEBUG_INFORMATION_FORMAT=dwarf-with-dsym`。
- 缓存命中后没有新截图是精确输入复用，任务摘要会明确说明；源码或工具链变化会重建。疑似缓存损坏时删除对应 Actions 缓存或递增缓存键版本，不能跳过失败检查。
- 并行任务仍排队时检查 macOS runner 并发额度；不应把排队时间当成编译耗时。
- IPA 不能安装：本工作流产物未签名，需自行签名；归档成功不等于设备签名有效。

将运行链接、提交 SHA、首个相关错误和复现步骤附在问题描述中。不要附真实密码、Cookie、密钥或未脱敏请求内容。

## AI 补全不可用

先在“更多 → AI 自动补全”中填写独立模型服务的 Base URL、协议、模型 ID 与密钥。Base URL 通常带 `/v1`，不要填写当前 ChatAPI 人工服务地址，也不要重复填写 `chat/completions` 等最终路径。

自动建议只在启用后、输入停顿约 1.2 秒且当前请求仍可回复时生成。可以手动生成、取消、采纳或放弃；旧请求、旧草稿对应的建议不会覆盖新输入。工具参数不符合已声明 schema 时不展示可采纳结果，应调整工具名称或补全要求后重新生成。

401/403 等 AI 错误只影响辅助模型，不会注销 ChatAPI Cookie 会话。超过大小限制、45 秒超时或重定向会失败并保留原草稿。模型建议不是已执行的工具结果，采纳后仍需核对并手动发送。
