# 架构与状态

## 组件职责

| 组件 | 职责 |
| --- | --- |
| `ChatAPIAdminApp` / `AppLock` | 注入共享状态、可配置应用锁、独立的敏感操作认证、非活动时遮挡内容 |
| `RootView` | 按本地锁、实例、会话验证结果选择界面 |
| `InstanceStore` | 实例列表、选中实例、已验证用户、会话恢复和失效处理 |
| `APIClient` | Cookie REST 请求、Origin、响应大小限制、协议解码、WebSocket 请求 |
| `WorkspaceConnection` | 实时状态、订阅、分页、命令确认、重连、草稿访问 |
| `AIAssistClient` / `AIComposerController` | 独立模型请求、响应限制、schema 校验、去抖取消、建议版本隔离 |
| `MessageComposerView` | 浮动玻璃编辑区、模式独立草稿、AI 建议预览与采纳 |
| `KeychainStore` | 设备本地的实例元数据、会话标记和回复草稿 |
| SwiftUI Views | 表单输入、确认和结果展示；服务端执行最终授权与校验 |

应用不嵌入服务器、Bark 服务端密钥或 R2 凭据，不请求尚未实现的设备令牌。

## 启动与会话

1. 从 Keychain 恢复实例，恢复上次选择的实例 ID；读取失败显示错误。
2. 默认通过设备所有者认证解锁。用户可在“更多 → 应用安全”关闭 Face ID / 设备密码锁，此时跳过启动和返回前台的本地应用认证；敏感管理操作仍独立要求设备认证。重新开启立即锁定，设置在本设备持久化。
3. 无已保存会话标记时显示登录；有标记时先请求 `/api/auth/session`。
4. 只有 `authenticated == true` 且存在用户对象才进入业务界面。
5. 服务器明确返回未认证或 401 时清除该实例的本地登录状态；网络故障、5xx 或解码失败保留标记并提供重试。
6. 进入后台后使已验证状态失效；应用锁开启时重新锁定，关闭时仍需在返回前台后重新验证服务器会话。每次前台会话只自动认证一次，用户取消后手动重试。系统认证的 active/inactive 切换不重复弹窗，所有情况下后台均遮挡内容。

本地密码登录允许填写 TOTP。网页登录使用非持久 WKWebView 完成服务器现有登录流程；用户点击“完成登录”后，仅导入适用于实例主机的 Cookie，再验证会话。没有增加自定义 OAuth 回调或 PKCE 协议。

Cookie 由系统 `HTTPCookieStorage.shared` 管理，不写入应用自建的 Cookie Keychain 记录。会话标记本身不能恢复失效或未持久化的服务器 Cookie。用户名与密码不被持久化；成功登录后清空密码和 TOTP。

切换实例会取消旧的会话验证资格、清除内存用户，并重建业务界面。较早完成的异步验证不能覆盖当前实例。业务 REST 收到 401 时通知实例存储退出登录；403 保留会话，以便呈现实际授权错误。

密钥显示、撤销和敏感设置在等待设备认证前绑定实例、已验证用户、会话代次与 APIClient。认证结束后重新检查绑定，不为旧操作取得新实例的客户端。批量操作每条请求前检查，异步结果返回后也检查；切换实例、注销或后台失效后，旧结果不能显示明文、覆盖列表或继续发下一条请求。已发出的服务端操作不能回滚，不自动重放。

## 实时连接与发送

连接状态是 `disconnected → connecting → connected`，收到有效工作台快照后才算连接成功。RootView 已验证恢复会话，WebSocket 直接使用 Cookie 握手，不再串行重复请求 `/api/auth/session`；握手 401 使当前会话失效，403 显示权限错误而不自动重试。同一已验证前台会话复用 APIClient 与 URLSession，并忽略旧客户端迟到的 401；重复选择当前实例也不重建连接。

会话验证请求与 WebSocket 握手超时均为 15 秒，另有独立的 15 秒首次快照截止时间。连接失败按 1、2、4、8、16、30 秒退避，提供“立即重连”取消等待；只有收到快照才重置次数。连接由 AdminTabView 持有，切换标签或打开详情保持连接，退出业务界面或进入后台才断开。显式断开会取消接收、超时、重连、分页和待确认命令。每轮连接有独立 ID，旧结果不能复活新连接；不会自动重放业务命令。

当前打开的时间线订阅会在新快照到达后重发。追加项按 ID 去重；删除会话同时删除内存时间线。工作台使用服务端游标分页，避免只显示初始 30 条会话。

收到有效快照后开始 WebSocket 控制帧心跳：每 20 秒 ping 一次，最多等 pong 10 秒。无响应或 ping 失败使用现有重连流程，不再无限保持假连接状态。断开、重连或新快照取消旧心跳与截止任务，回调同时检查连接 ID 和 ping ID，避免旧回调断开新连接。

每条命令携带新的 `command_id`、会话 ID 和请求 ID：

- 收到匹配三个 ID 的 `workspace.command_ack` 才清空输入。
- 收到 `workspace.command_error`、断线、取消或 15 秒超时，保留输入。
- 不自动重放业务命令。确认丢失时，服务器可能已经执行，重试前应检查时间线。
- 会话已关闭或请求 ID 已变更时，旧详情页不能继续发送；返回列表重新打开当前请求。

## 数据保存与隔离

| 数据 | 保存位置 | 范围 |
| --- | --- | --- |
| 实例列表 | Keychain `instances` | 此设备 |
| 选中实例、语言、是否启用应用锁 | UserDefaults | 此应用 |
| 登录标记 | Keychain `session-marker.<instance UUID>` | 实例 |
| 各模式文本、工具字段与补全要求 | Keychain `workspace-draft.<instance UUID>.<encoded components>` | 实例、用户、会话、请求 |
| 辅助模型配置及 API 密钥 | Keychain `ai-assist.<instance UUID>.<encoded owner>` | 实例与账号 |
| 时间线、用户信息、已显示的业务密钥 | 内存 | 当前界面 / 会话 |

Keychain 更新使用先更新、不存在再新增，避免先删除旧值造成失败时的数据丢失；属性为 `WhenUnlockedThisDeviceOnly`。实例列表先成功写入再更新内存。删除实例会删除其新格式草稿、辅助模型配置与会话标记，并清除适用于服务器地址的 Cookie。

旧版未区分实例的草稿不自动迁移，因为无法可靠判断归属；新实现不会读取这些记录。Cookie 按域和路径匹配，并不按端口隔离，因此独立服务器应使用不同主机名，同一主机上的多个实例可能互相影响登录和退出。

## 设置与网络边界

设置先加载目录与文档。原始值与文本编辑分别保存，提交时才解析数字并验证整数、有限性、最小/最大值和枚举。补丁只包含已更改且支持编辑的声明字段。结构化 JSON 可读取与保留；暂不提供对象/数组编辑器。

HTTP 仅允许用户明确选择开发用途的实例；默认要求 HTTPS。ATS 的全局 HTTP 许可用于实现这个按实例选择，具体限制由应用 URL 校验执行。实例只接受根地址，无用户信息、子路径、查询或片段。外部附件只接受 HTTPS，开发实例的 HTTP 许可不扩散到其他主机。证书验证继续使用系统默认信任。REST 只跟随同源重定向，避免凭据转发到其他来源或降级连接；网页登录允许 HTTPS 身份提供方跳转。

REST 先检查响应头中已知的 Content-Length，再以字节流读取，累计最多 1 MiB；无长度或分块传输同样受限，结束、拒绝或取消时取消底层任务，不再先完整下载到临时文件。WebSocket 单消息也限制为 1 MiB。同源比较规范化主机大小写和 HTTP/HTTPS 默认端口，仍拒绝换主机、非等效端口与降级。

辅助模型使用独立临时网络会话，禁用 Cookie、缓存和全部重定向。按输入快照取消旧生成，只允许当前快照采纳；不会自动发送或执行工具。旧版已按实例保存的纯文本草稿会迁移为回复草稿，工具模式拥有独立文本。详见 [AI 与编辑区设计](ai-assist.md)。
