# Ubiquitous Language

## Instance

A separately deployed ChatAPI server, identified by its HTTPS base URL and administered with its own authenticated session.

## Device Session

A revocable, device-bound credential issued by the compatibility server after local login or the mobile OIDC PKCE flow.

## Capability Catalog

A versioned declaration from an Instance of the administrator features and settings fields the client may render and mutate.

## Notification Policy

An Instance-level subscription describing which operational, pending-work, and security events are delivered to a registered Bark target.
